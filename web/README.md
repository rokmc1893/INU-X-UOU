# web/ — 정책핏 인천 웹 화면 (Next.js)

`final/`의 스트림릿 확정본과 **같은 판정, 같은 문장, 같은 숫자**를 담당자가 실제로 열어 볼 만한
화면으로 다시 지은 것이다. 판정 로직은 옮기지 않았다 — 파이썬이 낸 결과를 읽어 그리기만 한다.

```bash
cd web
npm install
npm run dev     # http://localhost:3000
```

## 무엇이 어디에 있나

| 경로 | 하는 일 |
| --- | --- |
| `data/policyfit.json` | 판정 결과 원본. 손으로 고치지 않는다 |
| `scripts/dump_data.py` | `final/`의 엔진을 돌려 위 파일을 다시 만든다 |
| `lib/data.ts` | 그 결과를 화면 단위로 자르고 센다. **새 판정을 만들지 않는다** |
| `app/globals.css` | 화면 규칙 전부. 컴포넌트별 CSS 파일을 두지 않았다 |
| `components/ui.tsx` | 문서 머리·항목 블록·표시·게이지·도장 |
| `app/*/page.tsx` | 화면 5개 |

### 데이터를 다시 뽑으려면

```bash
cd final && python ../web/scripts/dump_data.py
```

`06_앱/data`의 원장이 바뀌었을 때만 돌리면 된다. 웹 쪽에서 숫자를 손으로 적어 둔 곳은 없으므로,
이 파일만 바꾸면 화면의 모든 문장이 따라 바뀐다 — 화면 0의 결론 문장까지 포함해서다.

## 화면

| 주소 | 화면 | 성과축 |
| --- | --- | --- |
| `/` | 무엇을 보는가 | 범위와 한계 |
| `/budget` | 예산이 새는가 | C1 1순위 |
| `/links` | 사업끼리 이어지는가 | C1 2순위 |
| `/demand` | 산업 수요와 맞는가 | C1 3순위 |
| `/actions` | 조치 제안 | — |

산업 필터는 주소에 남는다(`/demand?ind=바이오`). 화면을 옮겨도 범위가 유지되고, 그대로 링크로
넘길 수 있다.

## 디자인이 지키는 것

이 도구의 주장은 "무엇을 판정했는가"가 아니라 **"어디까지만 판정했는가"**다. 화면 규칙도 거기서
나왔다.

- **사선(빗금)** — 판정하지 못한 칸에는 사선을 긋는다. 공문서에서 빈칸을 남기지 않으려고 긋는
  그 사선이다. 빈칸은 "문제 없음"으로 읽히기 때문에 비워 두지 않는다. 7개 성과축 띠, 축 표의
  `판정 못 함` 칸, 확신 게이지의 못 잰 몫이 모두 같은 사선을 쓴다.
- **도장** — 화면 0의 결론 상자에 「후보 · 확정 아님」 인장을 찍는다. 이 도구가 내놓는 것은
  확정이 아니라 후보라는 사실을 한 번은 못 박는다.
- **확신 게이지** — 숫자 옆에 "전체 몇 건 중 몇 건을 재 봤는지"를 같이 둔다. 사업 57건 중
  12건만 원장과 대조가 끝났다는 사실이 `10건 일치`라는 숫자보다 중요하다.
- **금지** — 체크 아이콘·진행률 링·신뢰도 %·별점처럼 **확정을 뜻하는 시각 요소를 쓰지 않는다**
  (결정로그 D-039의 금지 사항). 각 화면 하단의 「이 축의 한계」 문단은 지우지 않는다.

활자는 셋을 역할별로 쓴다 — 제목은 송명체(문서의 얼굴), 본문은 IBM Plex Sans KR, 금액·신호ID는
IBM Plex Mono(원장의 값).

## 알아 둘 것

- **바깥으로 나가는 요청은 글꼴 하나뿐이다.** `app/layout.tsx`의 Google Fonts 링크. 망 분리
  환경에 올릴 일이 생기면 이 줄을 지우고 글꼴을 `public/`에 받아 두면 된다. 나머지는 전부
  로컬 JSON이다.
- **화면 5(행정 절차 계층)는 없다.** `final/SCAFFOLD.md`에 골격만 있고 로직이 없다 — 없는 것을
  화면으로 만들지 않았다.
- `next/font`를 쓰지 않았다. 이 두 한글 서체는 next/font의 목록에 korean 서브셋이 없어서,
  그대로 쓰면 한글이 시스템 글꼴로 떨어진다.
