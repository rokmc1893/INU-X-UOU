# 취업정책 목적조건형 정합성 모델

기준일: 2026-08-12

## 1. 범위와 문제 재정의

이번 MVP는 전체 청년정책이 아니라 청년의 관외취업·지역 일자리 조기이탈과 직접 연결되는 **취업 관련 정책 포트폴리오**를 다룬다.

- 포함: 취업 목적 교육훈련, 인턴·일경험, 취업매칭, 기업 채용지원, 정규직 전환·근속지원, 채용과 직접 연결된 RISE 과제
- 조건부 포함: 대학·산업 인재양성 과제 중 공식 목표와 성과지표에 취업 또는 지역정주가 명시된 과제
- MVP 평가대상에서 제외: 주거, 교통, 문화, 마음건강 등 취업 외 정책. 단, 취업선택과 근속을 설명하는 외부조건으로 별도 기록

공식 통계상 최근 인천 청년 주소지는 순유입이므로 `청년 이탈률`을 주민등록 전출률 하나로 정의하지 않는다.

1. **관외취업률**: 취업한 대상 청년 중 주 사업장이 인천 밖인 사람의 비율
2. **지역 일자리 조기이탈률**: 인천 바이오직무에 입사한 대상 청년 중 3·6·12개월 안에 퇴사한 비율
3. **직무 이탈률**: 입사 후 바이오 생산·공정·QA/QC 경로를 벗어난 비율
4. **주소지 전출률**: 인천 거주 참여자 중 12·24개월 안에 타지역으로 전출한 비율. 장기 보조지표이며 취업 이탈과 합산하지 않음

## 2. 하나의 KPI가 아니라 목표 계층을 평가한다

```text
상위 공통성과
관외취업 감소 · 인천 양질 바이오직무 취업 증가 · 조기이탈 감소
        ↓ 기여경로
사업유형별 직접성과
훈련역량 · 인턴전환 · 기업채용 · 고용유지 · 일자리 질 개선
        ↓ 실행
사업별 산출물
모집 · 참여 · 수료 · 기업매칭 · 지원금 지급 등
```

모든 사업에 같은 취업률을 적용하면 기반조성·기업지원·근속지원의 역할이 왜곡된다. 반대로 각 부서가 작성한 자체 목표만 인정하면 쉬운 산출지표로 책임을 회피할 수 있다. 따라서 **사업 고유성과**와 **상위 취업·근속 성과로 이어지는 기여경로**를 함께 통과해야 한다.

## 3. 두 층의 정합성 진단

### A. 개별 과제의 수직 정합성

각 과제를 다음 사슬로 점검한다.

`관측된 문제 → 대상집단 → 사업목표 → 개입수단 → 직접성과 → 상위성과 기여 → 측정자료`

필수 진단 차원:

1. 문제 근거: 실제 기업수요·청년 이탈원인이 확인됐는가
2. 대상 적합성: 지원대상이 문제를 겪는 핵심집단과 일치하는가
3. 수단 타당성: 교육·인턴·보조금 등이 원인을 바꿀 수 있는가
4. 직접성과 적합성: 사업 고유목표를 제대로 측정하는가
5. 상위목표 기여: 인천 취업·직무질·근속으로 이어지는 경로가 있는가
6. 시간 정합성: 모집·교육·기업채용·예산·성과측정 시점이 맞는가
7. 근거 신뢰성: 분모, 기준일, 출처, 결측, 비교기준을 확인할 수 있는가
8. 실행 가능성: 예산·법적 권한·협력기관·데이터 책임자가 명확한가

### B. 포트폴리오의 수평 정합성

- 같은 청년·직무·교육내용을 여러 사업이 중복 지원하는가
- 교육 수료 뒤 기업매칭이나 근속지원으로 넘기는 연결자가 있는가
- 특정 학력·직무·기업규모가 정책 사이에서 빠지는가
- 한 사업의 종료시점과 다음 사업의 모집·채용시점이 어긋나는가
- 서로 다른 부서가 같은 성과를 다른 정의와 분모로 보고하는가
- 지역취업 성과가 낮은데도 교육인원 확대만 반복하는가

### C. 사업 고유목표로 면책되지 않게 하는 공통 관문

사업유형과 무관하게 다음 조건은 다른 높은 점수로 보상할 수 없는 관문으로 둔다.

1. 상위성과 중 적어도 하나로 이어지는 **브리지 KPI**가 있는가
2. 인천 사업장·바이오 직무·고용형태·6개월 추적을 위한 공통 데이터가 있는가
3. 외부 산업·기업·청년 수요근거가 있는가
4. 기존 참여자나 기업에 지원이 집중되는 사중손실·대체효과·형평성 위험을 점검했는가

## 4. 사업유형별 직접성과

| 사업유형 | 고유 직접성과 | 공통 상위성과와의 연결 |
|---|---|---|
| 교육훈련 | 직무역량 사전·사후 변화, 수료, 자격·과제 통과 | 해당 직무 취업, 교육–직무 일치, 6개월 근속 |
| 인턴·일경험 | 실제 직무수행, 중도이탈, 기업·청년 상호평가 | 면접·오퍼·직접고용 전환, 3·6개월 유지 |
| 취업매칭 | 적격 지원, 면접 참석, 오퍼·수락 | 인천 사업장 취업과 직무 일치 |
| 기업 채용지원 | 추가 청년채용, 정규직 전환, 채용계획 이행 | 지원 종료 뒤 고용유지와 일자리 질 |
| 근속지원 | 약정기간 유지, 이직·퇴사 사유 | 6·12개월 근속과 임금·직무 성장 |
| 대학·RISE 취업연계 | 현장과제, 실습, 기업연계 교과 | 졸업 후 인천 취업·직무 일치·정주 |

## 5. 평가 표현 방식

단일 종합점수를 예산 자동결정에 사용하지 않는다. `설계 정합성 / 관측 성과 / 근거 신뢰도`를 각각 별도의 0~5 벡터로 보여주되 합산해 1등을 정하지 않는다. 임무 관련성·브리지 KPI·추적 가능성은 보상 불가능한 관문으로 둔다. 각 세부 차원은 `충족 / 보완 필요 / 근거 부족 / 해당 없음`으로 표시하고 다음을 함께 제공한다.

- 판단 근거가 된 원문 문장과 링크
- 데이터의 최종 갱신일과 관측범위
- 사실·추론·추천 구분
- 신뢰도와 결측
- 담당부서 확인·이의제기 상태
- 계속·개편·통합·중단·추가조사 중 권고와 실행조건

수치 점수가 필요하면 같은 사업유형 안에서만 비교하고, `정합성`과 `근거 신뢰도`를 서로 다른 축으로 제시한다. 자료가 없다는 이유만으로 효과가 나쁘다고 판정하지 않고 `평가 불가능`으로 표시한다.

## 6. 바이오 MVP 적용 예시

### 청년도약기지 생산·품질관리 트랙

- 고유목표: 직무교육과 인턴을 통한 취업연계
- 직접성과: 수료율, 인턴매칭률, 실제 생산·품질 업무 수행, 직접고용 전환
- 상위성과: 인천 바이오 생산·QA/QC 취업, 3·6개월 근속, 관외취업 대체
- 현재 공백: 전체 산업을 합친 취업자 수만으로는 바이오 직무·사업장·근속을 판정할 수 없음

### 인천대 바이오의약품 제조·품질관리 과정

- 고유목표: 기업 맞춤형 제조·품질 실무인력 양성
- 직접성과: 직무역량, 수료, 협약기업 참여, 취업
- 상위성과: 인천 소재 바이오기업의 훈련직무 취업과 6개월 근속
- 현재 공백: 공개 취업률에 사업장 소재지·직무·고용형태·근속이 없음

두 사업의 성과지표를 동일하게 만드는 것이 목표가 아니다. 두 사업 사이에 `훈련 → 인턴·기업매칭 → 직접고용 → 근속`의 역할분담이 존재하는지, 아니면 같은 대상을 중복 교육하고 후속 연결이 끊기는지를 판정한다.

## 7. MVP의 성공과 실패

- 성공: 실제 사업 한 건이 근거에 따라 계속·개편·통합·보류되고, 다음 코호트에 공통 식별자와 취업·근속 추적항목이 포함됨
- 부분 성공: 보고서 작성시간은 줄지만 사업안과 성과측정 설계는 바뀌지 않음
- 실패: 수료·참여자 수를 다시 시각화하는 데 그치거나, 종합점수가 근거 없이 사업 순위를 정함

행정업무 효율만 좋아지고 관외취업·인천 취업·조기이탈 지표가 장기적으로 개선되지 않으면 이 서비스는 청년이탈 해결 서비스가 아니라 행정지원 도구로 평가한다.
