# LLM·규칙 기반 분석·사람의 역할 분담

기준일: 2026-08-13

## 기본 원칙

LLM은 **판단 후보 생성기**이며 정책결정권자가 아니다. 수치와 점수는 사전에 정의된 규칙으로 계산하고, 최종 계속·개편·통합 판단은 권한 있는 사람이 원문과 실행조건을 확인한 뒤 승인한다.

## 역할 분담

| 단계 | LLM | 규칙·일반 데이터 분석 | 사람 |
|---|---|---|---|
| 문서 수집 | 관련 문서 후보 분류 | 파일ID·URL·수집일·버전 저장 | 분석 범위 승인 |
| 정보 추출 | 목표·대상·수단·KPI·기간·예산 후보 추출 | 형식·단위·누락·중복 검사 | 원문 대조·수정 |
| 분류 매핑 | 정책용어를 산업·직무·역량 코드 후보에 연결 | 승인된 교차표·코드버전 적용 | 애매한 매핑 승인 |
| 정합성 진단 | 중복·공백·시차·대상·성과단절 후보와 설명 생성 | 사전 정의 규칙과 수치로 플래그·벡터 계산 | 맥락·예외·실행권한 판정 |
| 대안 생성 | 계속·개편·통합 후보, 반대가설, 필요자료 초안 | 비용·대상·시기 등 제약조건 검사 | 최종안 선택·책임 |
| 성과평가 | 정성자료 요약·퇴사사유 주제 후보 | 분모·비교집단·전환율·근속률 계산 | 인과해석과 공개 승인 |

## 3일 프로토타입에서 구현할 LLM 기능

1. 원문 문장과 함께 정책카드 필드 후보를 추출한다.
2. 세 사업의 대상·직무·교육·기업연계·성과지표 차이를 비교한다.
3. 중복·공백·시차·대상 불일치·성과단절 후보를 생성한다.
4. 각 후보에 찬성근거, 반대가설, 추가로 필요한 자료를 붙인다.
5. 계속·개편·통합을 위한 조건부 대안을 작성한다.

## 규칙 기반으로만 처리할 영역

- 시급↔월 환산, 수료·취업·근속 전환율
- 인천 사업장 여부, 계약기간과 임금하한 통과 여부
- 자료 최신성, 필수 필드 결측률, 출처 연결률
- 정책–사업–KPI 연결 관문 통과 여부
- 사전에 승인된 산업·직무·역량 코드의 적용
- `설계 정합성 / 관측 성과 / 근거 신뢰도` 벡터

## 사람의 필수 승인 지점

1. LLM이 뽑은 목표·대상·KPI가 원문 의미와 같은지
2. KSIC–KECO–NCS–학과–정책 태그 간 매핑이 타당한지
3. `미공개`를 `성과 없음`으로 잘못 해석하지 않았는지
4. 사업의 법적 권한·예산·협약과 정치적 맥락을 반영했는지
5. 계속·개편·통합·보류·중단 권고를 공식 문서에 반영할지

## 신뢰성 통제

- 모든 사실 주장에는 원문 인용문 위치와 URL을 붙인다.
- 근거가 없으면 답을 만들지 않고 `미확인`으로 반환한다.
- 인용문이 주장을 실제로 지지하는지 수작업 표본으로 검사한다.
- 모델명, 프롬프트, 교차표, 규칙과 입력 문서 버전을 저장한다.
- 같은 문서로 재실행했을 때 핵심 필드와 플래그가 안정적인지 확인한다.
- LLM 결과를 원문 수정이나 자동 예산결정에 직접 연결하지 않는다.

## 3일 검증 기준

- 필수 필드 추출 정확도 90% 이상
- 사실 주장 원문 연결률 100%
- 검증 표본에서 근거 없는 사실 주장 0건
- 핵심 정책–직무 매핑은 사람 승인 없이는 확정되지 않음
- 계속·개편·통합 권고에는 실행조건과 반대가설이 모두 포함됨

## 책임소재

- 시스템 제공자: 추출·규칙·모델 버전과 오류로그 관리
- 데이터 담당기관: 제공자료의 범위·기준일·정의 확인
- 현업 사업부서: 사업목표·실행조건·사실관계 확인
- 청년정책담당관: 상위 청년성과와 포트폴리오 정합성 검토
- 최종 결재권자·위원회: 공식 정책결정과 설명 책임

`AI가 추천했다`는 문장은 행정적 책임의 근거가 될 수 없다. 화면에는 모델 제안, 규칙 결과, 사람 승인상태를 분리해 표시한다.
