# 공개용 3축 정책 정합성 평가모델

기준일: 2026-08-13

## 1. 점수 표현 원칙

정책·사업마다 다음 세 축을 독립적으로 0~5로 표현한다.

1. **설계 정합성**: 문제·대상·수단·성과·상위목표가 논리적으로 연결되는가
2. **관측 성과**: 해당 사업이 약속한 직접성과와 상위 취업·근속 성과가 실제로 관측됐는가
3. **근거 신뢰도**: 판단에 사용한 자료가 최신이고 직접적이며 재현 가능한가

세 축을 합산하거나 평균내지 않으며 사업·부서 순위를 만들지 않는다. 각 축 아래의 세부항목, 근거문장, 데이터 결측과 이의제기 상태를 함께 공개한다.

## 2. 공통 0~5 앵커

| 점수 | 의미 |
|---:|---|
| 0 | 명시적으로 모순되거나 확인된 기준을 충족하지 못함 |
| 1 | 핵심 요소 대부분이 없고 연결 근거가 거의 없음 |
| 2 | 일부 요소가 있으나 연결이 약하거나 중요한 결측이 큼 |
| 3 | 기본 연결은 있으나 확인·자료·예외처리가 부분적임 |
| 4 | 대부분 직접 근거와 측정계획이 있으며 소수 보완점이 남음 |
| 5 | 직접·최신 근거, 측정 가능한 연결, 실행조건과 반증까지 확인됨 |
| 미측정 | 필요한 결과자료가 없어 점수를 산출할 수 없음 |
| 해당 없음 | 사업유형상 해당 차원을 적용하지 않음 |

`미측정`은 0점이 아니다. 낮은 성과와 자료 부재를 구분한다.

## 3. 설계 정합성 세부차원

| 차원 | 핵심 질문 |
|---|---|
| 상위목표 연결 | 관외취업 감소·인천 양질 바이오취업·조기이탈 감소 중 어디에 기여하는가 |
| 문제 근거 | 대상 청년·기업·직무의 실제 문제가 근거로 확인되는가 |
| 대상 적합성 | 자격·제외조건이 문제를 겪는 표적집단과 맞는가 |
| 수단 타당성 | 교육·인턴·매칭·기업지원이 관측된 원인을 바꿀 수 있는가 |
| 성과경로 | 사업 고유 KPI에서 상위 취업·근속으로 이어지는 브리지 KPI가 있는가 |
| 시간 정합성 | 모집·교육·기업채용·예산·측정 주기가 맞는가 |
| 포트폴리오 관계 | 다른 사업과 중복·공백·인계·역할분담이 설명되는가 |
| 실행 가능성 | 예산·권한·협력기관·데이터 책임자가 명확한가 |

설계 정합성 축도 세부점수 평균만으로 자동 확정하지 않는다. 상위목표 연결·브리지 KPI·측정 가능성은 보상 불가능한 관문이다.

## 4. 관측 성과 세부차원

사업유형에 맞는 직접성과와 공통 브리지 성과를 분리한다.

| 구분 | 예시 |
|---|---|
| 사업 고유 직접성과 | 역량 사전·사후 변화, 인턴매칭, 면접·오퍼, 순증채용, 정규직 전환 |
| 브리지 성과 | 인천 사업장 취업, 생산·공정·QA/QC 직무 일치, 생활임금 상당 임금, 3·6·12개월 유지 |
| 부정적 결과 | 중도이탈, 관외취업, 직무불일치, 지원 종료 후 퇴사, 대체채용·사중손실 |

비교집단이 없으면 `정책효과`가 아니라 `관측 전환성과`로 표현한다. 3일 공개자료 검증에서 6개월 근속자료가 없으면 `미측정`으로 둔다.

## 5. 근거 신뢰도 세부차원

| 차원 | 핵심 질문 |
|---|---|
| 출처 직접성 | 공식 원문·행정자료인가, 보도·자체발표·추정인가 |
| 최신성 | 정책과 산업현황을 반영할 만큼 최근인가 |
| 모집단·분모 | 대상·지역·직무·기간·분모가 명확한가 |
| 추적성 | 모든 사실에서 원문 문장·페이지·URL로 돌아갈 수 있는가 |
| 완전성 | 필요한 필드와 성과단계가 충분히 포함됐는가 |
| 일관성 | 다른 출처·기간·정의와 모순되지 않는가 |
| 검증상태 | 담당기관 또는 사람이 사실관계를 확인했는가 |

## 6. 공개 카드 예시

```text
사업: 청년도약기지 생산·품질관리 트랙

설계 정합성  3/5  [시스템 초안]
- 교육→인턴 경로는 명시됨
- 바이오 직무 특정과 6개월 브리지 KPI는 미확인

관측 성과     미측정
- 전체 사업의 수료·일경험·취업 집계는 존재
- 산업·직무·인천 사업장·근속 분해자료 없음

근거 신뢰도  3/5
- 공식 사업자료 사용
- 개인 코호트와 근속자료 부재

경고: 브리지 KPI 관문 미충족
이의제기: 없음 / 기관 미확인
```

위 숫자는 모델을 설명하기 위한 예시이며 실제 3일 분석 전 확정점수가 아니다.

## 7. 공개 시 통제

- 점수 옆에 상태·기준일·신뢰도를 같은 크기로 표시한다.
- 클릭하면 원문 근거, 반대가설, 필요한 추가자료를 볼 수 있게 한다.
- 부서가 제출한 반론을 원 평가와 나란히 공개한다.
- 모델·규칙이 바뀌면 이전 점수를 삭제하지 않고 새 버전과 차이를 보여준다.
- 점수만 다운로드해 예산 자동결정에 쓰지 못하도록 이용상 주의와 데이터 설명을 포함한다.
