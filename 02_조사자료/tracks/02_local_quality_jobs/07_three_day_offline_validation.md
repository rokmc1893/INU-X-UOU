# 3일 오프라인 정책 정합성 검증안

기준일: 2026-08-13

## 1. 검증 질문

> 공개된 실제 자료만으로 인천 바이오 취업정책 3개의 상위목표–사업목표–대상–수단–성과지표를 구조화하고, 사업 간 중복·공백·시차·성과단절을 원문 근거와 함께 찾아 계속·개편·통합 판단안을 만들 수 있는가?

이 검증은 서비스의 **문제진단 가능성, 데이터 가용성, 분석 재현성, 의사결정 산출물 완성도**를 확인한다. 취업·근속·청년이탈 감소 효과를 검증하지 않는다.

## 2. 분석대상

1. 인천 청년도약기지 생산·품질관리 트랙
2. 인천대 바이오의약품 제조·품질관리 양성과정
3. K-NIBRT Bio-All

인천재능대 바이오생명과의 지역기업 취업 발표와 RISE 과제는 보조 비교근거로만 사용한다. 세 사업은 모두 취업 또는 취업역량을 표방하지만 주관기관·대상·교육강도·기업연계·성과정의가 달라 수직·수평 정합성을 함께 시험할 수 있다.

## 3. 72시간 실행

### 1일차 — 근거 코퍼스와 수작업 정답지

- 공식 사업계획·모집공고·성과발표·상위 청년계획을 수집한다.
- 각 사업의 목표, 대상, 직무, 교육내용, 기업연계, 기간, 예산, 산출지표, 취업지표를 동일 양식으로 수작업 표기한다.
- 모든 사실에 원문 인용 위치와 URL을 부여한다.
- 공개되지 않은 필드는 추정하지 않고 `미공개`로 표시한다.

### 2일차 — 정합성 분석과 반대가설

- 수직 정합성: 문제근거→대상→수단→직접성과→인천 취업·근속 기여경로를 검사한다.
- 수평 정합성: 대상·교육·기업풀의 중복, 과정 간 인계 공백, 교육·채용 시차, 지표 정의 불일치를 검사한다.
- 최근 채용공고·고용통계와 비교하되 공고를 실제 채용수요와 동일시하지 않는다.
- 각 발견사항에 반대 해석과 필요한 추가자료를 붙인다.

### 3일차 — 의사결정 감사 카드

- 각 사업을 `계속 / 개편 / 통합 검토 / 근거 부족` 중 하나로 제안하되 자동 결론으로 표시하지 않는다.
- 청년도약기지와 인천대 과정의 역할분담 또는 연계안 한 건을 작성한다.
- 다음 기수부터 수집해야 할 공통 필드와 브리지 KPI를 제안한다.
- 원문 근거표, 불확실성, 사람이 확인해야 할 항목을 포함한 1~2쪽 결정 메모를 만든다.

## 4. 3일 안에 측정할 성공지표

| 검증영역 | 성공기준 | 실패기준 |
|---|---|---|
| 구조화 정확성 | 필수 필드의 수작업 정답 대비 일치율 90% 이상 | 목표·대상·KPI를 반복 오분류 |
| 근거 추적성 | 사실 주장 100%에 원문 위치·URL 존재 | 출처 없는 수치·사실 주장 발생 |
| 환각 통제 | 검증 표본에서 근거 없는 사실 주장 0건 | 미공개 정보를 사실처럼 생성 |
| 미스매치 발견 | 중복·공백·시차·지표단절 중 서로 다른 유형 3건 이상을 근거와 함께 제시 | 일반론만 제시하거나 원문으로 확인 불가 |
| 반증 가능성 | 각 핵심 판단에 반대가설·추가 필요자료 명시 | 한 방향 권고만 단정 |
| 결정 산출물 | 계속·개편·통합 판단조건과 담당기관·다음 행동이 명확 | 요약·검색 결과에 그침 |
| 데이터 현실성 | 공개/비공개/미존재 필드를 구분한 데이터 갭표 완성 | 확보 불가능한 데이터를 이미 있는 것처럼 전제 |

정책담당자 인터뷰가 없으므로 `현장 활용성`, `시간 절감`, `실제 정책 변경`은 이번 성공지표에 넣지 않는다.

## 5. 검증 단계의 정직한 명칭

| 단계 | 이번 3일 검증 여부 | 검증 내용 |
|---|---|---|
| 0. 문제·자료 타당성 | 가능 | 미스매치 존재와 공개자료 범위 |
| 1. 오프라인 분석 성능 | 가능 | 추출 정확성, 근거성, 미스매치 탐지 |
| 2. 행정 의사결정 유용성 | 불가능 | 담당자가 실제 판단을 바꾸는지 |
| 3. 사업 운영 변화 | 불가능 | 대상·교육·기업선정·KPI가 바뀌는지 |
| 4. 청년 취업·근속 효과 | 불가능 | 인천 취업·6개월 근속 증가 |
| 5. 청년 이탈 감소 | 불가능 | 관외취업·주소전출 감소 |

발표에서는 `3일 만에 청년이탈 감소를 검증했다`고 표현하지 않는다. 정확한 결론은 다음과 같다.

> 3일 검증으로 실제 정책자료에서 정합성 문제를 탐지하고 근거 있는 개편안을 만드는 기술·데이터 가능성을 확인했다. 청년 취업과 지역정착 효과는 아직 검증되지 않았으며 후속 코호트 평가가 필요하다.
