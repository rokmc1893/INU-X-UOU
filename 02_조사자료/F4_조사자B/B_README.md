## 3. 데이터 모델

네 파일은 ID로 연결된다. **조인 키를 지켜야 표가 하나의 지도로 작동한다.**

```
B2_demand_signal          B1_policy_portfolio
  signal_id (D-xxx)         stable_policy_id (IC-XXX-nnn)
        │                            │
        └──── 커버리지 행렬 ─────────┘
                (B4 §2에서 수기 매핑)
                             │
                             ├── policy_a ──┐
                             │              ├─ B3_linkage_evidence
                             └── policy_b ──┘     evidence_id (E-xx)
                             
B5_missing_data_requests
  request_id (R-xx) → 어느 신호/사업의 빈칸을 채우는지 why_needed에 명시
```

### ID 체계

| 접두사 | 의미 | 예시 |
|---|---|---|
| `IC-BIO-nnn` | 바이오 정책 | IC-BIO-004 바이오 커넥트 |
| `IC-SEM-nnn` | 반도체 정책 | IC-SEM-002 레전드 50+ 2.0 |
| `IC-ROB-nnn` | 로봇 정책 | IC-ROB-001 로봇랜드 |
| `IC-DIG-nnn` | 디지털·데이터 정책 | IC-DIG-001 양자클러스터 |
| `IC-CAR-nnn` | 미래차 정책 | IC-CAR-001 자율주행 부품 |
| `IC-AIR-nnn` | 항공 정책 | IC-AIR-001 대한항공 MRO |
| `IC-COM-nnn` | 산업 공통 | IC-COM-002 i-RISE |
| `D-nnn` | 수요신호 (D-0xx 공통, D-1xx 바이오, D-2xx 반도체, D-3xx 로봇, D-4xx 디지털, D-5xx 미래차, D-6xx 항공) | D-102 대기업편중 |
| `E-nn` | 연결 근거 | E-04 바이오 예산 이전 의혹 |
| `R-nn` | 결측 데이터 요청 | R-02 행정구역 코드 매핑 |

**ID는 절대 재사용하지 않는다.** 사업이 폐지돼도 행을 지우지 말고 `status`를 `종료`로 바꾼다. `stable_policy_id`의 'stable'이 그 뜻이다.

## 4. 지금 반드시 알아야 할 세 가지

### ① 인천 행정구역이 2026-07-01에 바뀌었다

2군 8구 → **2군 9구**. 중구 내륙+동구 → 제물포구, 중구 섬 → 영종구, 서구 → 서해구+검단구.

- 자치단체코드가 바뀌었으므로 **2026년 상·하반기 데이터를 그냥 이어붙이면 안 된다**
- MRO 사업 소관이 중구 → 영종구로 이동(IC-AIR-003 → IC-AIR-004)
- 로봇랜드 소재지 서구 → 서해구
- **군·구 단위 지도를 그리기 전에 R-02(코드 매핑표)를 먼저 확보할 것**

### ② 근거 등급이 낮다

52건 중 34건이 `SECONDARY_PRESS_ONLY`(언론보도만). 1차 출처 확인은 15건.
**완료기준의 "세부 3건 원문 연결"은 0건이다.** 이 폴더의 모든 판단은 잠정이다.

### ③ 중복 확정은 0건이다

역할중첩 **후보** 12건이 있을 뿐이다. `consideration_status`가 `NOT_PUBLICLY_VERIFIABLE`인 건을 "중복"으로 인용하면 안 된다.

## 5. 금지사항 (다른 에이전트가 이 데이터를 다룰 때)

**이 규칙을 어기면 조사자 B의 산출물 전체가 무효가 된다.**

1. **`UNKNOWN`을 추정치로 채우지 마라.** 빈칸은 실패가 아니라 조사 결과다. 근거 없이 채우면 `evidence_status` 필드의 존재 의미가 사라진다.
2. **`source_url` 없이 행을 추가하지 마라.** 출처가 없으면 등재하지 않는다.
3. **`evidence_status`를 임의로 승격하지 마라.** `SECONDARY_PRESS_ONLY` → `PRIMARY_VERIFIED`는 실제 원문을 확인했을 때만 가능하며, `CHANGELOG.md`에 무슨 문서를 봤는지 남긴다.
4. **역할중첩 "후보"를 "중복"으로 바꿔 쓰지 마라.** B3의 `note` 컬럼에 적힌 반대가설을 배제한 근거가 있어야 한다.
5. **`FORECAST` 신호를 현재 수요로 쓰지 마라.** D-601(MRO 2,000명)은 2031년 전망치다. 현재 부족인원과 섞으면 5년치 과잉투자를 정당화하게 된다.
6. **CSV를 손으로 고치지 마라.** `scripts/`의 파이썬을 수정하고 재실행한다. 그래야 이력이 남는다.
7. **`strategic_industry`를 배타적 분류로 쓰지 마라.** 양자는 바이오와 디지털데이터에 걸쳐 있고, 반도체·바이오는 같은 과 소관이라 예산이 섞여 있다. 산업별 합계를 낼 때 중복 계상 규칙을 먼저 정하라.

python3 build_b1.py      # → B1_policy_portfolio.csv
