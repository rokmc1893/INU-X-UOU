## 5.5 알려진 한계 — 발표에서 먼저 말할 것

숨기면 질의응답에서 터지고, 먼저 말하면 점수가 되는 항목들이다.

- **홀드아웃 셋이 없다.** 정답셋을 만든 쪽이 프롬프트도 고쳤으므로 42%→100%는 일반화 정확도가 아니라 동일 셋 반복 최적화다.
- **`_auto_repair`가 기권 정확도를 부분적으로 자기충족적으로 만든다.** null 필드를 `missing_fields`에 자동 기입하므로 "기권해야 함" 방향 케이스는 통과가 구조적으로 보장된다. 판별력은 양성 통제군(G32~G36) 쪽에만 있다.
- **`조정 필요 중복` 지표가 두 범위 모두 0건**이다. 현 코퍼스에 대상 요건이 완전히 겹치는 쌍이 없어서이며, 만들어 넣지 않았다.
- **풀 카드 16장 중 stage null 10장 / occupation null 8장** — 시설·R&D 사업이라 사슬에 참여하지 않는 게 맞지만, 화면에는 "사슬 밖"으로만 표시된다.
- **풀 카드의 인용은 원문이 아니라 B1 원장 재구성 텍스트 기준**이다. "원문 근거 인용"이라 뭉뚱그리면 과장이 된다.
- **인계 공백이 여전히 많다**(청년일자리 29쌍 / +바이오 72쌍). 원인은 `전직무`가 모든 직무와 겹치도록 설계된 것 + O(N²) 전수 비교다. 우선순위 스코어링과 상위 N건 컷이 실사용 전제다. 동일 부서 쌍은 Phase 6에서 "부서 내 조정"으로 구분했다.
