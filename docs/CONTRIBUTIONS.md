# 유소민의 역할과 기여

유소민은 정책핏 인천에서 데이터 조사·정리와 검증 설계, MVP 범위·사용 흐름 검토 및 발표 근거 정리에 참여했다. AI 조사·개발 도구의 산출물을 대조하고 사실·추론·미확인을 구분하는 기준을 정리했다.

2026-11-11 기준으로 기존 역할 소개, 저장소 파일·커밋과 관련 Codex 채팅을 대조했다. 개발·조사·문서화에는 Codex·Claude 등 AI 도구를 활용했으며, 팀 공동 작업과 본인의 담당 범위를 구분했다.

## 확인 근거

- **기존 프로필 및 TEAM_3_RESEARCH_ROLE_PLAN.md:** 개인 담당 경험과 조사자/제품책임자의 역할 구분을 확인했다. 조사자 A/B/C는 작업 역할이며 모든 결과가 본인의 직접 조사라는 뜻은 아니다.
- **Codex 「최종 제출물 분석 및 Q&A 대비」·「검증 및 한계 슬라이드 시각화」:** 발표 근거 검토와 시각화·Q&A 보완 작업을 확인했다.
- **F4의 452cac2, H001 및 팀 결정·증거 문서:** C 조사 자료 정리와 UX 검토의 연결 근거다. todotoday 등 다른 작성자의 앱·발표 전체 구현을 단독 기여로 옮기지 않았다.

## 검증 범위와 협업

해커톤 장려상과 앱 전체는 팀 공동 성과다. 규칙 테스트 통과를 취업률 개선·정책 효과로 해석하지 않는다. 자체 정답셋과 교차판정·홀드아웃의 한계를 유지한다. H002는 기존 색인에서 검증 요청 상태이며, 이번 기여 문서 작성으로 검증 완료 처리하지 않았다.

이번 변경은 역할 문서 정리다. 앱 테스트·실계정 연동·배포·대회 제출을 새로 수행한 결과로 표시하지 않는다. 채팅 원문과 계정 비밀값은 저장소에 옮기지 않았다.
