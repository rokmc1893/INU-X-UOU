# 유소민의 역할과 기여

정책·예산 자료 조사와 검증 설계에 참여하고, MVP 범위·사용 흐름과 발표 수치·질의응답을 정리했다.

## 주요 작업

| 영역 | 수행 내용 | 관련 코드·문서 |
|---|---|---|
| 정책·예산 조사 | 정책 담당 부서·예산 대응과 데이터 가용성 자료를 검토·정리하고 팀의 A/B/C 조사 결과를 제품 검토에 연결했다. | [02_조사자료/F4_조사자C](../02_조사자료/F4_조사자C) |
| 검증 설계 | MVP 후보·정답셋·평가 기준과 원문 근거를 검토하고 규칙 테스트·데이터 한계·정책 효과를 분리했다. | [03_제품설계/3단계_정합성_점검.md](../03_제품설계/3단계_정합성_점검.md) |
| UX·범위 검토 | 업무 진입경로와 사용자 시나리오, LLM 추출·규칙 판정·사람의 결정 경계를 검토했다. | [04_핸드오프/03_closed/H001_CODEX_TO_CLAUDE_DEMO_ENTRY_VERIFICATION.md](../04_핸드오프/03_closed/H001_CODEX_TO_CLAUDE_DEMO_ENTRY_VERIFICATION.md) |
| 발표·질의응답 | 최종 발표자료의 수치·적용 범위·한계를 확인하고 대본·유사 서비스 비교·Q&A 설명을 보완했다. | [05_발표자료](../05_발표자료) |

## 개발 범위

팀의 정책 조사·개발 결과를 바탕으로 데이터 근거와 사용 흐름을 점검했다. 조사 원장은 [F4](https://github.com/rokmc1893/F4)에서 관리한다.
