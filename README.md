## 현재 상태

- 상위 제품비전: **지역산업 수요와 정책 포트폴리오의 공백·중복·시차·대상·지역·예산 불일치를 진단하는 정책설계 워크벤치**
- 첫 검증 모듈: **2번 — 인천 청년의 역외취업을 줄이고 지역 내 양질의 직무 취업·근속을 늘리는 문제**
- 후속 독립 모듈: **3번 — 인천 전략산업 기업의 핵심인력 부족을 줄이는 문제**
- 진행 방식: 최대 15개 질문의 단계적 인터뷰. 사실·추정·가설을 구분하고, 충분한 검증 전에는 솔루션을 확정하지 않는다.
- 초기 작성 사용자: **반도체바이오과 등 정책 발의부서 실무자**
- 공동 검토 사용자: **청년정책담당관, 교육·RISE·일자리·기업지원·예산 담당자**
- 현재 검증 제약: **3일 이내, 실제 취업실험·취업자 인터뷰 없이 공개자료 기반 오프라인 검증**
- 이번에 검증하는 것: 실제 정책자료의 수요–정책 커버리지, 예산–수요 배분, 정책사슬 정합성 분석과 결정 메모 생성
- 이번에 검증하지 못하는 것: 취업·근속·청년이탈 감소 효과와 행정 현장 활용성
- 인터뷰 상태: **15개 질문 완료**
- 최종 통합안: `03_제품설계/FINAL_INCHEON_BIO_POLICY_FIT_PROPOSAL.md`

## 핸드오프 시작 방법

1. `04_핸드오프/HANDOFF_INDEX.md`에서 다음 번호를 확인한다.
2. Claude 요청은 `01_claude_to_codex`, Codex 결과는 `02_codex_to_claude`에 저장한다.
3. 상대 파일을 수정하지 않고 다음 번호의 새 파일로 응답한다.
4. 반영과 재검증이 끝난 교환은 `03_closed`로 이동한다.

## 두 트랙을 분리하는 이유

2번은 청년 관점에서 `원하는 직무`, `임금·고용 안정성`, `지역 내 취업`, `근속·경력 성장`을 성과로 본다. 3번은 기업·산업 관점에서 `미충원 인원`, `직무별 숙련 부족`, `채용 소요기간`, `전략산업 인재 확보`를 성과로 본다. 두 목표는 겹칠 수 있지만, 기업이 부족하다고 말하는 일자리가 청년에게 좋은 일자리라는 보장은 없으므로 별도 검증한다.
