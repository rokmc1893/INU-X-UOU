# 정책핏 인천 — 확정본

인천 6대 전략산업의 **사업**과 **산업 수요**를 대조해 어긋난 곳을 후보로 골라낸다.
모든 판정은 후보이며 확정은 부서 협의로 한다.

```bash
cd final && streamlit run app.py --server.port 8502
```

## 왜 새로 짰나

이전 버전은 청년 일자리 파이프라인(교육훈련→일경험→구직지원→매칭→채용지원→정착)
한 축으로만 판정했다. 그런데 조사자 C의 성과축 7개 중 **일자리는 5순위이고
조건부 보류**이며, C가 1·2순위로 꼽은 것은 예산 비효율과 산업 생태계다.
결정로그 D-001이 정한 타겟(산업·정책 연계 부족)과도 어긋나 있었다.

확정본은 **화면 순서를 C1 순위 그대로** 따르고, 수요 대조 축을 직무 하나에서
**지원 유형 7가지**로 넓혔다.

## 화면

| | 화면 | C1 축 |
|---|---|---|
| 0 | 무엇을 보는가 | 7축 전체 + 결론 |
| 1 | 예산이 새는가 | 1순위 · 정책 예산의 비효율적 사용 |
| 2 | 사업끼리 이어지는가 | 2순위 · 산업 생태계 형성 어려움 |
| 3 | 산업 수요와 맞는가 | 3순위 · 정책 실효성 저하 (+ 산업 태세) |
| 4 | 조치 제안 | — |

## 지금 자료로 내린 결론

```
대조한 산업 수요 42건 중 덮는 사업이 없는 것 5건 — 전부 공급망·금융
  인력   23÷23 덮임      사업이 주는 것:  인력 13건
  기술    6÷6  덮임                      기술 10건
  시설    6÷6  덮임                      시설  9건
  공급망  2÷5  덮임                      판로  5건
  금융    0÷2  덮임                      금융  4건 / 공급망 3건
```

**정책이 몰려 있는 곳(인력·기술)과 모자란 곳(공급망·금융)이 다르다.**
이것이 "지역 산업·정책 연계 부족"의 실측이다.

판정 엔진(`extract` / `detect` / `store` / `refdata` / `industry`)은 `06_앱`의 것을
그대로 쓴다. 검증된 것을 복사해 갈라놓지 않기 위해서다 — `06_앱`의 테스트 62건이
그대로 유효하다.

## 판정에 AI가 관여하지 않는 지점

LLM은 `engine/extract.py`에서 **원문에서 항목을 뽑는 데만** 쓴다. 무엇이 중복인지,
무엇이 공백인지 고르는 일은 전부 파이썬 규칙이 한다. 원문에 없는 값은 채우지 않고
비워 두며, 인용은 원문에 그대로 있는 문장만 쓴다.

## 알려진 한계 (화면에도 적혀 있다)

- 7축 중 **3축(지역격차·정책신뢰도·기업경쟁력)은 판정하지 못한다.** 자료가 없어서다.
- 예산 대조가 끝난 사업은 10건뿐이다. 나머지는 "예산이 없다"가 아니라 "아직 확인 못 했다".
- 사업 57건 중 17건은 원문에 **주는 것(수단)이 안 적혀 있어** 어떤 수요와도 못 맞춘다.
- 6대 산업 목록의 근거는 **언론기사 1건**이다(`SECONDARY_PRESS_ONLY`). 종합계획 원문 미확보.
  발표에서 "인천시가 지정한 6대"라고 단정하지 않는다.
- 직무 수요신호 5건 중 2건은 **가상 표본**이다. 워크넷·NCS API가 차단돼 실데이터가 없다.
- 사업명을 읽지 못한 카드 4건이 있다. 지우지 않고 표시해 뒀다.
