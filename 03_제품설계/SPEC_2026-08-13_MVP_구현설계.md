## 3. 데이터 모델 — 속성 그래프

**노드**
- `(:Policy {policy_id, name, status, owner_dept, executor, problem, target, intervention, occupation, region, application_period, budget, output_kpi, outcome_kpi, source_url, source_span, missing_fields, data_type})`
- `(:Demand {signal_id, occupation, geography, period, value, source_url, data_type})`

**엣지 (규칙 산출 — LLM이 만들지 않음)**
- `(:Policy)-[:HANDOFF]->(:Policy)` — 명시된 인계 (upstream/downstream)
- `(:Policy)-[:OVERLAP_HARMFUL {reason}]->(:Policy)` — 해로운 역할중첩 후보
- `(:Policy)-[:OVERLAP_INTENTIONAL {reason}]->(:Policy)` — 의도적 중첩 (지역·난이도·대상 세분이 다름)
- `(:Policy)-[:COVERS]->(:Demand)` — 수요신호 커버

**규칙 4종 (detect)**
| 판정 | 논리 |
|---|---|
| 인계 단절 | HANDOFF 없음 ∧ 동일 target+occupation 정책 존재 |
| 공백 후보 | Demand에 있는 occupation을 어떤 Policy도 COVERS 안 함 |
| 해로운 중첩 후보 | target·occupation·period 겹침 ∧ 양방향 HANDOFF 없음 ∧ 세분 차이 없음 |
| 의도적 중첩 | 겹치되 region 또는 대상 세분이 다름 → 낭비 아님 표시 |

## 4. LLM 사용 (extract.py 한 곳뿐)

- 모델: gpt-4o-mini (배치·개발) / 시연 라이브 버튼은 gpt-4o
- 출력: `response_format=json_object`, 카드 스키마 강제
- **프롬프트 계약:** 원문에 없는 필드는 반드시 `null` + `missing_fields`에 기록 (기권). `source_span`에 근거 문단 원문 인용 필수
- 키: 개발·배치는 개인 키, 최종 산출·시연은 팀 키 (중간점검 때 사무국 확인)
- `detect.py`에는 `import openai` 없음 — 판정에 LLM 불개입의 물증
