4. OpenAI API 빠른 시작 가이드 (한글 요약) 
아래 내용은 OpenAI 공식 문서(platform.openai.com/docs)의 핵심을 한글로 요약한 것입니다. 더 자세한 
내용은 공식 문서를 참고하세요. 
4-1. 준비하기 
1. Python이 설치된 노트북을 준비합니다. (설치가 어려우면 Google 
Colab(colab.research.google.com)을 브라우저에서 바로 사용해도 됩니다) 
2. 터미널에서 OpenAI 라이브러리를 설치합니다:  pip install openai 
3. 배부받은 API 키를 환경변수로 등록하거나 .env 파일에 저장합니다. 
# .env 파일 (프로젝트 폴더에 생성) 
OPENAI_API_KEY=배부받은_팀_API_키 
4-2. 첫 호출 — 텍스트 생성 
from openai import OpenAI 
from dotenv import load_dotenv   # pip install python-dotenv 
load_dotenv() 
  
client = OpenAI()   # OPENAI_API_KEY 환경변수를 자동으로 읽음 
  
response = client.chat.completions.create( 
    model="gpt-4o-mini",          # 저비용 모델. 품질이 필요하면 gpt-4o 
    messages=[ 
        {"role": "system", "content": "너는 지역문제 분석 전문가야."}, 
        {"role": "user", "content": "울산 시내버스 배차 문제의 원인을 3가지로 정리해줘."}, 
    ], 
) 
print(response.choices[0].message.content) 
• role 구분: system(AI의 역할·규칙 지정) / user(질문·요청) / assistant(이전 AI 답변). 대화를 이어가려면 
이전 메시지들을 messages 배열에 계속 담아 보내야 합니다. 
• 모델 선택: 반복 호출·테스트는 gpt-4o-mini(저렴), 최종 시연·복잡한 분석은 gpt-4o 권장. 팀 예산 
한도가 있으니 개발 중에는 mini를 기본으로 쓰세요. 
• 주요 파라미터: temperature(0~2, 낮을수록 일관된 답변·높을수록 창의적), max_tokens(응답 길이 
상한) 
4-3. 활용 패턴 예시 
• 구조화 출력(JSON): "JSON으로만 답하라"고 지시하고 response_format={"type": "json_object"}를 
추가하면, 결과를 파싱해 화면·대시보드에 바로 연결할 수 있습니다. 
• 데이터 분석 결합: 공공데이터 CSV를 pandas로 읽어 요약·통계를 만든 뒤, 그 결과를 프롬프트에 
넣어 해석·인사이트를 생성하는 방식이 가장 실용적입니다. (원본 데이터 전체를 넣으면 토큰 낭비) 
• 이미지 입력: gpt-4o 계열은 이미지를 입력으로 받을 수 있습니다. messages의 content에 image_url 
항목을 추가하면 사진 기반 서비스(예: 위험상황 사진 신고)를 시연할 수 있습니다. 
• 챗봇 시연: Streamlit(pip install streamlit)을 쓰면 파이썬 몇십 줄로 채팅 화면을 만들 수 있어 발표 
시연에 유용합니다.
