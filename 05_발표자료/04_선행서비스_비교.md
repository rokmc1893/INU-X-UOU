# 선행 서비스·기존 방식 비교

> **담당:** 데크 담당자 · **우선순위 1** · **예상 1시간**
>
> **왜 이게 1순위인가:** 루브릭 §7에 따르면 "기존 대안 비교가 전혀 없음"이면 **CRE1 최대 1점, CRE2·CRE3 각각 최대 3점** 상한이 걸린다. 지금 이 표가 없어서 창의성 30점 중 최소 9점이 묶여 있다. 코딩 없이 웹 확인만으로 풀 수 있는 가장 싼 점수다.

---

## 채우는 방법

1. 아래 표의 빈칸을 채운다. **최소 2개, 가능하면 3개.**
2. 각 서비스는 **실제로 접속해서 확인**하고, 확인한 화면·메뉴를 `확인한 근거` 칸에 적는다. ("~일 것이다" 금지)
3. 확인한 URL과 확인일을 `03_증거원장.csv`에 등록한다.
4. 마지막 `남은 공백` 섹션이 이 문서의 진짜 목적이다. 표는 그걸 증명하기 위한 재료다.

---

## 비교표

비교 기준은 아래 5개로 고정한다. 기준을 바꾸면 비교가 아니라 나열이 된다.

| 기준 | 온통청년 | 기업마당 | 인천 일자리포털 | **정책핏 인천** |
|---|---|---|---|---|
| **누가 쓰는가** | 정책을 찾는 청년 | 지원사업을 찾는 기업 | | **정책을 만드는 공무원** |
| **무엇을 입력하는가** | 나이·지역·관심분야 | 업종·규모·지역 | | **기존 사업 1건** |
| **무엇을 출력하는가** | 나에게 맞는 정책 목록 | 신청 가능한 지원사업 목록 | | **이 사업과 다른 사업들의 역할중첩·공백·인계단절** |
| **정책 간 관계를 다루는가** | 아니오 (개별 정책 나열) | 아니오 | | **예 — 관계 자체가 산출물** |
| **어떤 결정을 돕는가** | 개인의 신청 여부 | 기업의 신청 여부 | | **사업의 유지·보완·연결·통합·신설** |

> 위 표의 온통청년·기업마당 칸은 **추정 초안**이다. 반드시 직접 접속해 확인하고 수정할 것.

### 추가 검토 대상 (선택 — 여유 있으면)

행정 절차 쪽에도 "기존 사업 검토"를 다루는 장치가 이미 존재한다. 이걸 함께 비교하면 CRE1이 5점권으로 올라간다.

| 기존 방식 | 무엇을 하는가 | 한계 (우리가 채우는 지점) |
|---|---|---|
| 지방재정 투자심사 | 일정 규모 이상 신규사업의 타당성 심사 | |
| 유사·중복사업 검토 | 예산 편성 시 유사사업 확인 | |
| 청년정책조정위원회 | 청년정책 시행계획 심의·조정 | |

## 남은 공백 (이 문서의 결론)

아래 문장을 확인한 근거로 뒷받침해서 완성한다. 이게 발표 슬라이드에 그대로 들어간다.

> 기존 서비스는 전부 **"정책을 소비하는 사람"**을 위한 **검색·안내 도구**다.
> 정책을 **설계하는 사람**이, **이미 있는 사업들 사이의 공백과 역할중첩**을 근거와 함께 판단하도록 돕는 도구는 확인되지 않았다.
>
> 그리고 이 공백은 우연이 아니다 — (여기에 "왜 이 공백이 계속되는가"를 한 문장. 예: 정책 검색은 정책명·요건만 있으면 되지만, 정책 간 관계 판단은 각 사업의 대상·수단·시기·KPI를 같은 구조로 정규화해야 하고 그 정규화가 사람 손으로는 비용이 너무 크기 때문)

**주의:** 루브릭 CRE1은 조사 없이 "최초·유일"이라고 주장하면 **0점**이다. 반드시 `확인한 범위 내에서는` 이라는 한정을 붙인다.
