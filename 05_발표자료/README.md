## 데크 담당자가 지금 바로 할 일 (우선순위 순)

루브릭 예비평가에서 확인된 **가장 큰 감점 구멍 2개**를 메우는 작업이다. 코딩과 병렬로 진행한다.

### 1순위 — `04_선행서비스_비교.md` 채우기 (예상 1시간)

현재 상태: **CRE1 = 2점 / 5점.** 기존 대안 비교가 전혀 없어서 CRE2·CRE3에도 최대 3점 상한이 걸린다. **합계 9점 이상이 걸린 구멍이고, 조사 없이 웹 확인만으로 메울 수 있다.**

최소 2개, 가능하면 3개를 같은 기준으로 비교한다. 후보:
- 온통청년 (youthcenter.go.kr) — 전국 청년정책 통합 안내
- 기업마당 (bizinfo.go.kr) — 중소기업 지원사업 통합 검색
- 인천 일자리포털 — 지역 채용·정책 안내
- (선택) 지자체 정책 중복성 검토 관련 기존 행정 절차 — 재정투자심사, 유사중복사업 검토

핵심은 "이런 게 있다"가 아니라 **"이들은 전부 시민에게 정책을 찾아주는 검색·안내 도구이고, 정책을 만드는 사람이 기존 사업들 사이의 공백·중첩을 판단하도록 돕는 도구는 없다"**는 공백을 증명하는 것이다.

### 2순위 — `02_발표서사.md` 검토 후 슬라이드 착수 (예상 2시간)

Claude가 서사 초안을 넣어둔다. 시각자산이 현재 전무해서 **PRE2 = 2점 / 5점**이다. 특히 필요한 도식 3개:
- 인과사슬 도식 (플랫폼 직접효과 → 행정 중간효과 → 사업성과 → 지역 장기성과)
- 문제 재타겟팅 도식 (청년유출 → 산업·정책 연계 부족)
- 데모 화면 4단계 흐름도

## 작업 규칙

1. **슬라이드에 들어가는 모든 수치는 `03_증거원장.csv`에 먼저 등록한다.** 등록 안 된 수치는 슬라이드에 올리지 않는다.
2. **사실 / 추론 / 가설 / 미확인**을 섞지 않는다. 발표에서도 "확인된 것"과 "우리 가설"을 구분해 말한다.
3. **가상 데이터를 실데이터처럼 표시하지 않는다.** 화면과 슬라이드에 `실데이터` / `가상데이터` 라벨을 붙인다. 루브릭상 이건 `DATA_INTEGRITY` 플래그 사유이고 AI3·REG2가 동시에 0점이 된다.
4. **`06_금지표현_체크리스트.md`를 제출 직전에 반드시 통과시킨다.**
