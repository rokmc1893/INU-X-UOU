# 직접효과 측정 설계 (파일럿용)

> **이 문서에는 성과 수치가 없다.** 아직 측정하지 않았기 때문이다. 여기 있는 것은 *무엇을 어떻게 재겠다는 설계*뿐이다.
> 근거 없는 수치를 넣는 순간 루브릭 §7 `UNVERIFIED_CLAIM` 대상이 된다 — 파일럿 실행 전까지 이 문서에 숫자를 채우지 않는다.

## 1. 무엇을 측정하는가 — 귀속 범위 (D-002)

측정 대상은 **정책핏의 직접효과 1단계뿐**이다. 취업률·기업 매출·청년 정착은 측정 대상이 아니며, 도구의 성과로 귀속하지 않는다.

```
[측정한다]  근거 완전성 · 검토 소요 · 누락 탐지
[측정 안 함] 사업 보완·통합 실행률 (행정 중간효과 — 파일럿 이후)
[귀속 안 함] 취업·임금·근속 / 청년 정착 (D-002)
```

## 2. 주 지표 — K1: 검토서 초안 완성까지의 작업 단계 수

**정의:** 주무관이 신규사업 1건의 「유사·중복 사업 자체 검토서」(A3 3단계 입력문서, E020) 초안을 완성하기까지 수행한 **개별 작업 단계의 수**.
1단계 = 검색 1회, 전화 1통, 문서 열람 1건, 표 작성 1행 중 하나. 작업 로그에 체크로 기록한다.

**왜 시간이 아니라 단계 수인가.** `[추론]` 소요 시간은 업무 중단·회신 대기에 좌우되어 도구 효과와 무관한 분산이 크다. 단계 수는 관찰자가 셀 수 있고, 도구가 줄이려는 대상(부서 간 왕복 조회)과 직접 대응한다.

| 항목 | 내용 |
|---|---|
| 기준선(A) | 도구 없이 현행 방식으로 1건 수행 — **미측정** |
| 처치(B) | 도구 사용 후 1건 수행 — **미측정** |
| 판정 | 동일 주무관이 서로 다른 사업 2건을 A·B 순서 무작위로 수행, 단계 수 비교 |
| 실패 조건 | B가 A보다 많거나 같으면 **도구가 실패한 것으로 기록한다** |

## 3. 보조 지표

| ID | 지표 | 정의 | 측정 방법 | 현재 |
|---|---|---|---|---|
| K2 | 누락 탐지 | 현행 방식이 놓쳤으나 도구가 찾아낸 관련 사업 수 | A·B 산출물의 사업 목록 차집합 | 미측정 |
| K3 | 오탐 부담 | 도구가 제시한 후보 중 담당자가 "관련 없음"으로 기각한 비율 | 후보별 담당자 판정 기록 | 미측정 |
| K4 | 근거 추적 가능성 | 검토서 항목 중 원문 링크로 즉시 확인 가능한 비율 | 산출물 항목별 링크 유무 | 도구 산출물은 100% (링크 자동 부착) — 현행 방식과 비교 미실시 |
| K5 | 추출 품질 | 필드 정확도 / 기권 정확도 / 인용 실재율 / 중첩 오판 회피 | 정답셋 31건 자동 채점 | **측정됨** — 100 / 100 / 89 / 100% (자체 정답셋, 교차판정 전 잠정) |

K5만 현재 측정되어 있다. K1~K4는 사람이 실제 업무를 수행해야 나오는 값이라 파일럿 없이는 만들 수 없다.

## 4. 파일럿 설계 (최소 실행안)

| 항목 | 내용 |
|---|---|
| 대상 | 인천시 청년정책담당관 청년일자리팀 주무관 2인 (A1 레지스트리 기준, **접촉 전**) |
| 표본 | 신규·개편 검토 대상 사업 4건 (인당 A방식 1건 + B방식 1건) |
| 기간 | 2주 |
| 관찰 | 작업 로그는 참여자가 직접 체크, 연구자는 집계만 |
| 중단 조건 | K3(오탐 기각률)가 50%를 넘으면 파일럿을 중단하고 규칙을 재설계한다 |

**성공 기준을 미리 못박는다:** K1이 줄지 않으면 이 도구는 "보기 좋은 대시보드"이지 업무 도구가 아니다. 그 결과가 나오면 그대로 보고한다.

## 5. 지금 말할 수 있는 것과 없는 것

| 말할 수 있다 | 말할 수 없다 |
|---|---|
| 추출·판정 품질을 정답셋 31건으로 측정했고 지표를 공개한다 | 검토 시간이 단축된다 |
| 검토서 초안이 자동 생성되고 근거 링크가 붙는다 | 공무원이 이 도구를 쓸 것이다 |
| 측정 설계와 실패 조건을 미리 정해두었다 | 정책 품질이 개선된다 |

**발표에서 이 문서를 쓰는 법:** "효과를 측정했다"가 아니라 **"효과를 어떻게 측정할지, 그리고 어떤 결과가 나오면 실패로 인정할지 미리 정해두었다"**고 말한다.
